# Pairs Trading Backtester (Notebook)

This repository contains a Python-based pairs trading backtester project with notebook-driven analysis.

Contents
- `pairs_backtester.ipynb`: Exploratory notebook workflow.
- `pairs_backtester_executed.ipynb`: Executed notebook with output.
- `pairs_backtester_final.ipynb`: Final summary notebook for interview presentation.
- `requirements.txt`: Python dependencies for data analysis and backtesting.

Quick start

```bash
cd pairs_trading_repo
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Open the notebooks in Jupyter Lab and run the analysis cells. This repository is now focused on a robust notebook/script workflow rather than Streamlit.
